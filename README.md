# 🛡️ FraudGuard AI

### AI-Powered Image Fraud Detection for Food Delivery Scams

**FraudGuard AI** ek innovative frontend application hai jo food delivery ecosystems mein hone wale "fake item" aur "synthetic complaint" scams ko tackle karta hai. Ye tool specifically AI-generated images aur manual manipulations ko detect karne ke liye design kiya gaya hai.

---

## 🚀 Key Features for Interviewers

- **Advanced Image Processing:** React-based drag-and-drop system with real-time preview.
- **Developer Sandbox (Demo Mode):** Integrated feature toggle to switch between 'Authentic' and 'Fraudulent' UI states—perfect for live demonstrations.
- **Deep Scan Simulation:** Simulated pixel-pattern scanning and metadata verification to mimic real AI behavior.
- **Industry-Ready Handover:** Includes a clear "Data Contract" for backend developers, showcasing frontend-backend collaboration skills.
- **Dark Mode UI:** Optimized for high-end developer experience with Tailwind CSS dark/light modes.

## 🛠️ Technical Stack

- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS (Modern Glassmorphism Design)
- **State Management:** React Hooks
- **Documentation:** Markdown

### 💻 Installation & Usage

### Clone the Repo:

git clone [https://github.com/siddharthsharma983/fraudguard-ai.git](https://github.com/siddharthsharma983/fraudguard-ai.git)

### Launch Dev Server:

npm run dev
